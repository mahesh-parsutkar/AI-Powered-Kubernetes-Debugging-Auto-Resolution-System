# AI-Powered-Kubernetes-Debugging-Auto-Resolution-System
Design and implemented an AI-powered debugging system for Kubernetes clusters that automatically detects, analyzes, and suggests fixes for pod failures, crash loops, and resource issues using log analysis and event monitoring.
This project is an AI-powered Kubernetes debugging and self-healing system that automatically detects, analyzes, and resolves issues in a Kubernetes cluster using log analysis, metrics monitoring, and AI-based root cause detection.
The system reduces manual debugging effort by automatically identifying issues such as:
•	CrashLoopBackOff
•	OOMKilled (Out of Memory)
•	ImagePullError
•	High CPU/Memory usage
and performs automated remediation actions.
🧠 Key Features
✅ Real-time Kubernetes monitoring using Prometheus
✅ Centralized logging with ELK Stack
✅ AI-based log analysis using Python + LLM
✅ Automated root cause detection
✅ Self-healing (auto-remediation) engine
✅ Alerting via Slack / Email
✅ CI/CD pipeline integration
